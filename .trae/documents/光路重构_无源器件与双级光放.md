# test2.py 光路重构：插入无源器件与两级光放

## Summary

把 `scripts/ganlin/test_gnpy/test2.py` 的链路从"Tx → Fiber → OA → Rx"改为完整光路：

```
Tx → Mux → VOA(Tx侧) → OA1 → FIU1 → Fiber → FIU2 → OA2 → VOA(Rx侧) → Demux → Rx
```

- Mux / Demux / VOA / FIU 全部只做衰减建模，**插损按 C 波段与 L 波段分别配置**，定义写在
  `scripts/ganlin/test_gnpy/eqpt_config.json`。
- 两级 OA 都用 `C96_SGA_22dBm` / `L96_SGA_21dBm`（C/L 双波段），各自工作在额定总输出功率
  22 / 21 dBm（增益由 `p_max − 该波段输入总功率` 自动推导）。
- 其余输出（逐波长 SNR_NLI / SNR_ASE、SRS 转移量、功率谱图）保持既有口径。

### 2. 新建 `gnpy/bplab/passives.py`

```python
class PassiveParams(Parameters):
    """无源器件参数：loss = {'C96': x, 'L96': y}，单位 dB"""
    def __init__(self, **kwargs):
        self.type_variety = kwargs.get('type_variety', '')
        self.loss = dict(kwargs.get('loss', {}))


class BandAttenuator(_Node):
    """纯衰减器件（Mux / Demux / VOA / FIU），插损按波段区分。"""
    def __init__(self, *args, params=None, **kwargs):
        super().__init__(*args, params=PassiveParams(**(params or {})), **kwargs)
        self.passive = True

    def __call__(self, si):
        attenuation_db = zeros(si.number_of_channels)
        for band_name, loss_db in self.params.loss.items():
            f_min, f_max = DWDM_BAND_RANGES[band_name]
            attenuation_db[is_in_band(si.frequency, si.slot_width,
                                      {'f_min': f_min, 'f_max': f_max})] = loss_db
        si.apply_attenuation_db(attenuation_db)   # 逐波道衰减，numpy 广播
        return si


def load_passive_library(filename) -> Dict[str, PassiveParams]:
    """读取 eqpt_config.json 中 bplab 扩展段 Passive（YANG 不识别，故单独解析）"""
```

- `is_in_band` 来自 `gnpy.core.info`（与放大器分带同一判据，含 `±slot_width/2`）。
- `__call__` 直接改 `si.pch`，返回同一个 `si`，与 `Fused` 的不可变风格不同但只影响本器件；
  因为只衰减功率、不改频率，`pch` 缩放即可让 `signal/ase/nli` 同步衰减。
- 未落在任何已定义波段内的波道衰减为 0 dB（本案例 63 波全部落在 L96 ∪ C96 内）。

## Assumptions & Decisions

1. **L 波段插损取 C + 0.5 dB**：用户只给了一组典型值（Mux 3、VOA 5、FIU 1.5、Demux 3）却要求区分 C/L，故按"L 波段器件插损略高 0.5 dB"处理，全部数值显式写在 `eqpt_config.json` 里，如需改成别的差值只改配置。
2. **无源器件用 bplab 自定义元素**：gnpy 的 `Fused` 只支持标量损耗，`Roadm` 会引入均衡与 OSNR 语义，均不满足"只考虑衰减 + 区分 C/L"的要求。
3. **`Passive` 段放顶层**：与 `Edfa`/`Fiber` 平级，由 bplab 加载器在 YANG 校验前摘掉并单独解析；`gnpy/**` 上游文件零改动（符合项目规则）。
4. **两级 OA 都钉在额定输出总功率**：增益 = `p_max − 输入总功率`；因此 OA2 的增益恰好等于 `FIU1 + 跨度损耗 + FIU2`，OA1 的增益只取决于 Mux/VOA 插损与波道数。
5. **预期工作点**（按损失预算手算，用于验证）：

   | 器件 | C96 | L96 |
   |---|---|---|
   | OA1 输入总功率 | +0.91 dBm | +0.05 dBm |
   | OA1 增益 / 输出 | 21.09 dB / 22 dBm | 20.95 dB / 21 dBm |
   | 光纤输入总功率 | 20.5 dBm（+5.59 dBm/波） | 19.0 dBm（+3.95 dBm/波） |
   | 光纤输出总功率 | 3.5 dBm（−11.41 dBm/波） | 2.0 dBm（−13.05 dBm/波） |
   | OA2 输入总功率（经 FIU2 后） | 2.0 dBm | 0.0 dBm |
   | OA2 增益 / 输出 | 20.00 dB / 22 dBm | 21.00 dB / 21 dBm |
   | 接收端每波道 | ≈ −0.91 dBm | ≈ −3.05 dBm |

6. **入纤功率大幅提高会显著恶化 NLI**：光纤输入每波道从 −6 dBm 提到 +5.6/+4.0 dBm，
   预计 `SNR_NLI` 从 ~54 dB 掉到 ~30 dB 量级；`SNR_ASE` 因放大链 NF 改善会上升。这是光路变化的结果，不是 bug。
